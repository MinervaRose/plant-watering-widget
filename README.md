## About

A small Electron widget using Open-Meteo weather data to suggest whether plants may need watering.

Run with:

```powershell
npm.cmd install
npm.cmd start
```

Recommended setup:

```text
Windows
Node.js LTS v22.x
Electron 25
PowerShell with npm.cmd
```
